# 🫀 Heart Disease Analysis – An In-Depth Clinical Data Analysis Using MySQL, Tableau & Flask

## 📌 Project Name
**Heart Disease Analysis – An In-Depth Clinical Data Analysis Using Tableau**

---

## 📖 Overview
This project presents an interactive analysis of Heart Disease clinical data using **Tableau dashboards integrated into a Flask-based web application**.  

The system enables users to visualize and explore heart disease patterns, risk factors, demographic distributions, and key medical indicators through an intuitive and interactive web interface.

The main objective of this project is to transform raw healthcare data into meaningful insights that help in understanding cardiovascular risk factors.

---

## 🎯 Project Objectives
- Analyze heart disease dataset using structured query techniques in **MySQL**
- Perform Exploratory Data Analysis (EDA)
- Build interactive dashboards using **Tableau**
- Integrate Tableau dashboards into a **Flask web application**
- Provide a clean and user-friendly visualization interface

---

## 🧠 Key Insights Explored
- Age distribution of heart disease patients  
- Gender-based disease comparison  
- Chest pain type analysis  
- Cholesterol and blood pressure trends  
- Maximum heart rate vs disease presence  
- Correlation between clinical attributes and diagnosis  

---

## 💾 Dataset Description

The dataset contains clinical parameters commonly associated with heart disease diagnosis:

- Age  
- Sex  
- Chest Pain Type  
- Resting Blood Pressure  
- Serum Cholesterol  
- Fasting Blood Sugar  
- Resting ECG  
- Maximum Heart Rate Achieved  
- Exercise Induced Angina  
- ST Depression  
- Target (Heart Disease Presence)
